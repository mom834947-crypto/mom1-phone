# Audrey setup (your computer)

1. Install **TeamViewer** for Windows/Mac from the official site: https://www.teamviewer.com/
2. Sign in or use personal/free mode as applicable.
3. Ask Mom to open your HTTPS guide link and finish the Persian steps.
4. Ask her for the **Your ID** number shown in QuickSupport.
5. In your TeamViewer, enter that ID and request connection.
6. Wait until she taps **Allow / Accept** on her phone.
7. If you can see but not tap, she still needs the TeamViewer add-on + Accessibility enabled (the guide covers this).

## No Mom password needed
QuickSupport is designed around **Your ID + live approval**, not an account she must create.
