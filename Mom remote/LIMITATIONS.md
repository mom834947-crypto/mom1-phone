# What Android security prevents (important)

This HTML page is only a guide. Remote help requires **TeamViewer QuickSupport** (and usually an add-on) plus Mom’s live permission.

## Allowed with consent (typical QuickSupport session)
- View her screen (MediaProjection / screen capture prompt)
- Remote tap/swipe **after** Accessibility / manufacturer add-on is enabled
- Help her change settings she can normally change
- Help open apps and walk through menus
- Help install apps from Play Store / permitted sources **if Android allows and she approves prompts**

## Commonly blocked or restricted by Android/Samsung
- Silent remote control with **no** user prompts
- Bypassing lock screen / PIN / biometrics after reboot (she must unlock)
- Disabling Play Protect / installing blocked apps without her interaction
- Fully controlling some secure settings screens (OEM-dependent)
- Capturing password fields / banking apps in some cases (may blank or block)
- Unattended access after reboot without her opening the support app again (QuickSupport is attended)
- Bypassing Auto Blocker / unknown-app install protections on newer One UI
- Guaranteeing connectivity when Iran filtering blocks TeamViewer or Google Play

## Honest product statement
**One link → big Persian buttons → Mom installs QuickSupport → Mom approves Android permissions → Mom tells you Your ID → you connect with TeamViewer on your computer.**

If Play Store or TeamViewer is unreachable from her Iranian ISP that day, the guide still cannot create a remote session until the network path works.
