مرحله ۳ از ۶

اجازه نمایش صفحه

اگر پنجره‌ای آمد و پرسید صفحه را نشان بدهی، این دکمه انگلیسی را بزن:

Start now
یا Allow

مرحله ۴ از ۶

اگر گفت افزونه لازم است

اگر نوشته بود باید چیزی بیشتر نصب شود، این دکمه انگلیسی را بزن:

Download
یا Install

اگر چنین چیزی ندیدی، برو بعدی.

راهنما

روشن کردن دسترسی

  1. برو به تنظیمات گوشی
  2. بزن روی دسترسی‌پذیری
    (ممکن است نوشته باشد Accessibility)
  3. برو به برنامه‌های نصب‌شده
  4. اسم TeamViewer را پیدا کن
  5. کلید را روشن کن
  6. اگر دکمه انگلیسی Allow دیدی، همان را بزن

ادامه

دسترسی را روشن کردی؟

اگر برنامه از تو خواست دسترسی را روشن کنی، انجام بده.
اگر نخواست، برو بعدی.

مرحله ۵ از ۶

عدد را برایم بفرست

داخل برنامه، یک عدد بزرگ می‌بینی.
بالای آن ممکن است انگلیسی نوشته باشد:

Your ID

همان عدد را در پیام یا تلفن برایم بفرست.

مثال شکل عدد: 123 456 789

رمز لازم نیست. فقط همین عدد را بفرست.

یا Accept

تا وقتی با هم کار می‌کنیم، گوشی را روشن نگه دار.
